# Security

## Credential handling

Codex Usage does not read, copy, log, or store ChatGPT access tokens. It communicates with the locally installed `codex app-server` over standard input/output and asks Codex to manage authentication.

Do not submit credentials, session cookies, or access tokens in a public issue.

## Reporting a vulnerability

Please open a GitHub security advisory for the repository rather than a public issue. Include the affected version, impact, and reproduction steps, but redact all credentials and personal data.
